# Suggested 10 meaningful Git commits

Run these in order from inside `delosantos-project-2`. Each commit records a real development milestone.

1. `git add starter-page.html index.html assets/vendor && git commit -m "Add Mentor Bootstrap starter template"`
2. `git add assets/img && git commit -m "Add template image and favicon assets"`
3. `git add assets/css/main.css && git commit -m "Include original Mentor stylesheet"`
4. `git add assets/js/main.js && git commit -m "Include original Mentor interactions"`
5. `git add index.html && git commit -m "Create KCC landing page structure"`
6. `git add assets/css/kcc-custom.css && git commit -m "Apply KCC navy and gold visual theme"`
7. `git add assets/js/kcc-custom.js && git commit -m "Add KCC page enhancements"`
8. `git add README.md && git commit -m "Document project setup and deployment"`
9. After checking the site on mobile and desktop, edit any details that need correction, then run `git add . && git commit -m "Polish responsive layout and content"`
10. After adding approved school photos/logo or any final corrections, run `git add . && git commit -m "Finalize KCC landing page for deployment"`

Do not create empty or misleading commits. Make the relevant change before each commit. You can add more commits whenever you fix a bug or improve a section.

- Confirm the home page is named `index.html` at the repository root.

- Test the deployed URL in a private/incognito browser window.
