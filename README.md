# Kabankalan Catholic College, Inc. — Landing Page

A customized landing page built from the provided **Mentor Bootstrap template** (Bootstrap 5.3.7).

## Project folder
`delosantos-project-2`

## Run locally
Open `index.html` in a browser. For a local server, use VS Code Live Server or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Project structure
- `index.html` — KCC landing page
- `assets/css/main.css` — original Mentor template styles
- `assets/css/kcc-custom.css` — KCC color theme and responsive custom styles
- `assets/js/main.js` — original Mentor template scripts
- `assets/js/kcc-custom.js` — small KCC-specific enhancements
- `assets/vendor/` — Bootstrap and template libraries
- `assets/img/` — template image assets

## GitHub Pages
1. Create a public GitHub repository named `delosantos-project-2`.
2. Upload/push this project to the repository's `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

## Important content note
The contact details, institutional mission, founding year, and four pillars were based on publicly available KCC information at the time this project was prepared.
