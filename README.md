# Kabankalan Catholic College, Inc. — Landing Page

A customized landing page built from the provided **Mentor Bootstrap template** (Bootstrap 5.3.7).

## Project folder
`delosantos-project-2`

## Run locally
Open `index.html` in a browser. For a local server, use VS Code Live Server or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Project structure
- `index.html` — KCC landing page
- `assets/css/main.css` — original Mentor template styles
- `assets/css/kcc-custom.css` — KCC color theme and responsive custom styles
- `assets/js/main.js` — original Mentor template scripts
- `assets/js/kcc-custom.js` — small KCC-specific enhancement
- `assets/vendor/` — Bootstrap and template libraries
- `assets/img/` — template image assets

## Git status
The project has a local Git repository on branch `main` with more than 10 commits. Run `git log --oneline` to review the history.

## GitHub Pages
1. Create a public GitHub repository named `delosantos-project-2`.
2. Connect this local project to the new repository and push the `main` branch:
```bash
git remote add origin https://github.com/YOUR-USERNAME/delosantos-project-2.git
git push -u origin main
```
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

## Content and image notes
The institutional founding year, mission, four pillars, and contact information were based on publicly available KCC information when this project was prepared. Replace them with school-approved KCC photos and an official logo before final submission if available. Verify phone number and office hours with the school before publishing.
